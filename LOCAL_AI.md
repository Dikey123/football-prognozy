# Локальные ИИ-прогнозы

`gen_gpt.py` обращается только к Ollama на `127.0.0.1`. Он не использует OpenAI API и не запускает облачный веб-поиск. Прогноз строится по данным, уже находящимся в `data.json` и `results.json`.

## Настройка на Windows

1. Установите Ollama с [официальной страницы для Windows](https://ollama.com/download/windows), если она ещё не установлена.
2. Запустите PowerShell в папке проекта и выполните `.\setup_local_ai.ps1`.
3. Скрипт загрузит `qwen3:4b` (примерно 2,5 ГБ) и создаст задачу Windows: ежедневно в 12:00, а также при входе после 12:00.

Компьютер должен быть включён и пользователь должен войти в Windows. Если компьютер выключен в 12:00, задача выполнится при следующем входе. Генерация локальная; передача `gpt.json` в приложение требует интернет-соединения и входа Git Credential Manager для GitHub.

Локальная модель не ищет новости в интернете: она анализирует форму и источники, уже собранные приложением. Порог 60% — только оценка самой модели, не гарантия результата.
